# Saved plans

Plans for bigger features, kept here so they survive.

Claude Code's plan mode writes to one scratch file per conversation, outside
this project, and each new plan in that conversation overwrites the last one.
A plan worth keeping is copied here, where it is in git and can be opened any
time.

Each file starts with a **Status** line: planned, in progress, or done (with the
commit it shipped in).
